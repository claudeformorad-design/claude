# النظام المحاسبي الفندقي — Hotel Accounting System

نظام محاسبي متكامل للفنادق (وليس نظام حجوزات PMS): قيد مزدوج، دليل حسابات هرمي، فترات محاسبية، تعدد عملات، صلاحيات دقيقة عبر RLS، وواجهة عربية RTL افتراضيًا مع دعم الإنجليزية.

**الحالة: المرحلة 1 مكتملة** — راجع [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) (المخطط وهيكل المجلدات والقرارات المفتوحة).

| المرحلة | المحتوى | الحالة |
|---|---|---|
| 1 | الإعداد، المصادقة والأدوار، دليل الحسابات، دفتر الأستاذ (قيد يدوي)، ميزان المراجعة | ✅ |
| 2 | الفوليو والإيرادات، المدفوعات، الفواتير | ⏳ |
| 3 | الذمم المدينة/الدائنة، المشتريات، المصروفات | ⏳ |
| 4 | الأصول الثابتة، المخزون، مراكز التكلفة | ⏳ |
| 5 | التقارير المالية الكاملة، لوحة التحكم، التصدير | ⏳ |
| 6 | الضرائب، إقفال الفترات، الموافقات، الصلاحيات الدقيقة | ⏳ |

## التقنيات
Next.js 16 (App Router) · TypeScript (strict) · Supabase (PostgreSQL + Auth + RLS) · Tailwind CSS 4 + shadcn/ui · React Hook Form + Zod · decimal.js · Vitest

## التشغيل

```bash
npm install
cp .env.example .env.local        # ضع رابط ومفتاح مشروع Supabase

# تطبيق الترحيلات على مشروع Supabase
npx supabase link --project-ref <project-ref>
npx supabase db push

npm run dev                       # http://localhost:3000
```

بعد التسجيل، صفحة **إعداد الفندق** تُنشئ الفندق وتجعلك مديرًا عامًا، مع دليل حسابات فندقي افتراضي وأقسام وسنة مالية — كلها قابلة للتعديل.

## الاختبارات

```bash
npm test            # اختبارات الوحدة للمنطق المحاسبي (القيد المزدوج، ميزان المراجعة، المبالغ، السنة المالية)
npm run test:db     # ترحيلات + اختبارات SQL على PostgreSQL محلي مؤقت (التوازن، عدم التعديل، العكس، RLS، الفترات المقفلة)
npm run typecheck && npm run lint
```

`test:db` يتطلب PostgreSQL 15+ مثبتًا محليًا (يستخدم `initdb` في مجلد مؤقت، ومحاكاة مصغرة لـ `auth.uid()` الخاصة بـ Supabase).
